# P1: BME280 data acquisition

Status: **IMPLEMENTED IN SOURCE — NOT YET BUILT OR VERIFIED ON TARGET**.

## Design

- Driver: unchanged Bosch Sensortec BME280 SensorAPI, pinned to a specific commit.
- Platform adapter: `src/sensors/bme280_port.c` via RP2350 `hardware_i2c`.
- Interface: `I2C1`, GPIO2 SDA / GPIO3 SCL, 100 kHz; BME280 address `0x76`.
- Settings: forced mode, temperature oversampling 2x, pressure 4x, humidity 1x.
- Sampling interval: 1 second; actual conversion delay calculated by Bosch API.
- Outputs: temperature in 0.01°C, humidity in 0.01%RH, pressure in Pa,
  formatted by `src/main.c` for USB CDC.
- The I2C read-probe scan and all five sensor identity checks run **once at boot**.
- Sensor Manager owns periodic data sampling; it is not a generic framework.

## Expected console (illustrative only)

```text
Sensor Manager: BME280 ready (forced mode, 1 Hz)
BME280: temp=25.34 C, humidity=48.51 %RH, pressure=1013.28 hPa
```
